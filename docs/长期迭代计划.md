## 二、优化点清单（含证据，供实施时逐条勾销）

> 每条包含：问题 → 证据位置 → 建议方案。实施时按此清单核对完成度。

### A. 时间轴清晰度（v3.3 核心）

- [x] **A1 非激活连接线可读性**（v3.3.0 已落地）
  - 问题：非激活连线 opacity 0.25 + 1px 虚线，叠加在轨道背景网格上几乎不可见。
  - 证据：`TimelineView.tsx:1601`（`targetOpacity = 0.25`）、`:1792-1796`
  - 方案：opacity 提到 0.4–0.5 / 线宽 1.5px；加浅色 halo（`paint-order: stroke`）与网格分离；causal/foreshadow 增加端点形状区分（实心/空心箭头）。

- [x] **A2 卡片宽度复合估算**（v3.4.0 已落地）
  - 问题：卡片宽度只由标题长度决定，无视时间范围/地点/角色内容，导致截断或浪费。
  - 证据：`timelineLayout.ts:7-10`（`getEventCardWidth`）
  - 方案：`getEventCardWidthForEvent` 宽度 = f(标题, 时间范围, 地点, 角色) 复合公式；可读下限 232px；`computeTimelineLayout` 接受 `cardWidthFor` 注入。

- [x] **A3 瀑布子行视觉分隔**（v3.4.0 已落地）
  - 问题：同一轨道多个子行仅 8px 间隙，无分隔线/行号/隔行背景，事件归属难辨。
  - 证据：`timelineGrid.ts`（装箱算法）+ `TrackLane` 渲染
  - 方案：TrackLane 渲染子行虚线分隔 + 奇数子行 3% 背景交替。

- [x] **A4 折叠轨道连线锚点修复**（v3.4.0 已落地）
  - 问题：折叠轨道仍占瀑布布局高度，跨轨道连线终点"飘在空中"。
  - 证据：`TimelineView.tsx` 连线层
  - 方案：折叠轨道入/出边直接跳过；几何源共用折叠感知高度。

- [x] **A5 事件状态与相对事件标识**（v3.3.0 已落地）
  - 问题：draft 状态点是灰色半透明 8px 圆点；相对事件（章节/第N天）与绝对事件外观无差别。
  - 证据：`EventCard.tsx:31`、`:283-291`
  - 方案：draft 状态点用实色；相对事件加虚线边框或"相对"角标；时间范围 semibold + 持续时长胶囊底色。

- [x] **A6 标尺标签跳过降级**（v3.4.0 已落地）
  - 问题：相邻主刻度太近时整体跳过，形成大段无标签区。
  - 证据：`TimelineView.tsx` DateRuler
  - 方案：`formatMajorTickDegraded` 先降级为年份/短格式，仍放不下才跳过。

- [x] **A7 Today 线贯穿轨道区**（v3.3.0 已落地）
  - 问题：Today 线仅限 44px 标尺高度，无法跨轨道比对"今天"。
  - 证据：`TimelineView.tsx:1546-1560`
  - 方案：Today 线延伸到画布全高（轨道区内淡化为背景参考线）。

- [x] **A8 连线手柄发现性**（v3.4.0 已落地）
  - 问题：连线手柄 `opacity-0 group-hover:opacity-100`，不 hover 无从知晓可连线。
  - 证据：`EventCard.tsx`
  - 方案：首次进入时间轴 4.5s 内手柄常亮（`connectionHintVisible`）。

- [x] **A9 背景网格与标尺刻度强制对齐**（v3.4.0 已落地）
  - 问题：背景网格用固定 `zoom` 间隔，月/年模式下与真实日历边界的标尺刻度逐渐错开。
  - 证据：`TimelineView.tsx` TrackLane
  - 方案：`timelineGridBackground.ts` 从 `getXAtTime` 映射真实刻度边界生成 CSS gradient；新增 `chooseAdaptiveTickLevel` / `sampleTickTimestamps` 预算控制。

- [x] **A10 Script 视图工具栏选中反馈**（v3.4.0 已落地）
  - 问题：分段控件第 5 个 Script 按钮跳路由后永不显示激活态。
  - 证据：`TimelineView.tsx` ViewModeSegment
  - 方案：路由匹配 `/script` 时保持高亮。

### B. 主题 / 字体一致性（v3.3 核心）

- [x] **B1 修复 `font-pixel` / `font-smiley` 工具类编译**（v3.3.0 已落地）
  - 问题：`tailwind.css` 的 `@theme` 只声明 `--font-sans/--font-mono`，`font-pixel`/`font-smiley` 类从未编译（产物 CSS 中不存在），PomodoroTimer 8 处 + SplashOverlay 1 处为死代码。
  - 证据：`src/styles/tailwind.css:32-57`；`src/components/ui/PomodoroTimer.tsx:349,384,435,467,493,531,550,556`；`src/components/layout/SplashOverlay.tsx:170`
  - 方案：`@theme` 中补充 `--font-pixel`/`--font-smiley` 变量映射，使工具类真正生效。

- [x] **B2 全局字体切换彻底化**（v3.4.0 已落地）
  - 问题：RichEditor 硬编码 `font-mono`；"无衬线"字体主题下编辑器仍用等宽，与直觉不符。
  - 证据：`src/components/ui/RichEditor.tsx`；`src/features/settings/components/FontSelector.tsx`
  - 方案：新增 `editorFollowsFontTheme` 偏好（UI store persist）；开启后编辑器跟随界面字体主题（sans→sans、mono→mono、pixel→pixel、smiley→mono）。

- [x] **B3 收口字体设置入口**（v3.4.0 已落地）
  - 问题：`setFontTheme` store 方法未被调用（死代码），SettingsView 直接 set patch；FontSelector 在外观/编辑器两个 tab 重复挂载。
  - 证据：`src/stores/ui.ts`；`src/components/views/SettingsView.tsx`
  - 方案：FontSelector 增加 `variant='ui' | 'editor'`，外观 tab 只配界面字体，编辑器 tab 只配编辑器字体 + 跟随主题开关。

- [x] **B4 强调色与 MC 主题解耦提示**（v3.5.0 已落地）
  - 问题：MC 主题 `--accent` 固定 `#6BA84E`，自定义强调色无效且无提示。
  - 证据：`themes.css`；`SettingsView.tsx`
  - 方案：`mcUseCustomAccent` 偏好 + 设置页提示；开启后以内联 `--accent` 覆盖 MC 默认草绿；新增自由取色器。

## 四、迭代执行纪律（每阶段通用）

1. **每次改动遵循 `AGENTS.md`**：先读后写、禁 `any`、禁裸 CSS、禁改已发布迁移。
2. **测试先行**：每项优化点至少 1 个单元测试 + 涉及时间轴时跑 `tests/e2e/timeline-` 子集。
3. **截图留证**：UI 改动前后截图存入 `docs/截图留证/`（git 跟踪），方便对比验收。
