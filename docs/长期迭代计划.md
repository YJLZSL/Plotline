## 二、优化点清单（含证据，供实施时逐条勾销）

> 每条包含：问题 → 证据位置 → 建议方案。实施时按此清单核对完成度。

### A. 时间轴清晰度（v3.3 核心）

- [ ] **A1 非激活连接线可读性**
  - 问题：非激活连线 opacity 0.25 + 1px 虚线，叠加在轨道背景网格上几乎不可见。
  - 证据：`TimelineView.tsx:1601`（`targetOpacity = 0.25`）、`:1792-1796`
  - 方案：opacity 提到 0.4–0.5 / 线宽 1.5px；加浅色 halo（`paint-order: stroke`）与网格分离；causal/foreshadow 增加端点形状区分（实心/空心箭头）。

- [ ] **A2 卡片宽度复合估算**
  - 问题：卡片宽度只由标题长度决定，无视时间范围/地点/角色内容，导致截断或浪费。
  - 证据：`timelineLayout.ts:7-10`（`getEventCardWidth`）
  - 方案：宽度 = f(标题, 时间范围, 地点) 复合公式；最小宽度提到 240px 保证三行信息可读。

- [ ] **A3 瀑布子行视觉分隔**
  - 问题：同一轨道多个子行仅 8px 间隙，无分隔线/行号/隔行背景，事件归属难辨。
  - 证据：`timelineGrid.ts:371-404`（装箱算法）+ `TrackLane` 渲染
  - 方案：子行间浅色分隔线 + hover 整行高亮（`EventCard.tsx:172` 已有 `data-row` 可复用）；多行时隔行 5% 背景交替。

- [ ] **A4 折叠轨道连线锚点修复**
  - 问题：折叠轨道仍占瀑布布局高度，但 `trackTopByIndex` 只给 24px，跨轨道连线终点"飘在空中"。
  - 证据：`TimelineView.tsx:1680-1693` vs `:1719-1733`
  - 方案：`trackTopByIndex` 与 `eventLayout.trackHeights` 共用同一份折叠感知几何源；折叠态跳过其入/出边。

- [ ] **A5 事件状态与相对事件标识**
  - 问题：draft 状态点是灰色半透明 8px 圆点；相对事件（章节/第N天）与绝对事件外观无差别。
  - 证据：`EventCard.tsx:31`、`:283-291`
  - 方案：draft 状态点用实色；相对事件加虚线边框或"相对"角标；时间范围 semibold + 持续时长胶囊底色。

- [ ] **A6 标尺标签跳过降级**
  - 问题：相邻主刻度太近时整体跳过，形成大段无标签区。
  - 证据：`TimelineView.tsx:1464-1475`
  - 方案：间距不足时降级为只显示年份，而非直接跳过。

- [ ] **A7 Today 线贯穿轨道区**
  - 问题：Today 线仅限 44px 标尺高度，无法跨轨道比对"今天"。
  - 证据：`TimelineView.tsx:1546-1560`
  - 方案：Today 线延伸到画布全高（轨道区内淡化为背景参考线）。

- [ ] **A8 连线手柄发现性**
  - 问题：连线手柄 `opacity-0 group-hover:opacity-100`，不 hover 无从知晓可连线。
  - 证据：`EventCard.tsx:274`
  - 方案：首次进入时间轴时短暂高亮手柄提示；或长按卡片边缘进入连线模式。

- [ ] **A9 背景网格与标尺刻度强制对齐**
  - 问题：背景网格用固定 `zoom` 间隔，月/年模式下与真实日历边界的标尺刻度逐渐错开。
  - 证据：`TimelineView.tsx:2048-2060`
  - 方案：网格由 `getXAtTime` 对齐最近刻度边界计算，消除"网格与竖线打架"。

- [ ] **A10 Script 视图工具栏选中反馈**
  - 问题：分段控件第 5 个 Script 按钮跳路由后永不显示激活态。
  - 证据：`TimelineView.tsx:1281-1292`
  - 方案：路由匹配时高亮 Script 按钮。

### B. 主题 / 字体一致性（v3.3 核心）

- [ ] **B1 修复 `font-pixel` / `font-smiley` 工具类编译**
  - 问题：`tailwind.css` 的 `@theme` 只声明 `--font-sans/--font-mono`，`font-pixel`/`font-smiley` 类从未编译（产物 CSS 中不存在），PomodoroTimer 8 处 + SplashOverlay 1 处为死代码。
  - 证据：`src/styles/tailwind.css:32-57`；`src/components/ui/PomodoroTimer.tsx:349,384,435,467,493,531,550,556`；`src/components/layout/SplashOverlay.tsx:170`
  - 方案：`@theme` 中补充 `--font-pixel`/`--font-smiley` 变量映射，使工具类真正生效。

- [ ] **B2 全局字体切换彻底化**
  - 问题：RichEditor 硬编码 `font-mono`；"无衬线"字体主题下编辑器仍用等宽，与直觉不符。
  - 证据：`src/components/ui/RichEditor.tsx:82`；`src/features/settings/components/FontSelector.tsx:23`
  - 方案：提供"编辑器跟随字体主题"开关；无衬线主题下编辑器用 sans 栈。

- [ ] **B3 收口字体设置入口**
  - 问题：`setFontTheme` store 方法未被调用（死代码），SettingsView 直接 set patch；FontSelector 在外观/编辑器两个 tab 重复挂载。
  - 证据：`src/stores/ui.ts:73-83`；`src/components/views/SettingsView.tsx:438,467`
  - 方案：统一走 store 方法；两个 tab 拆成"界面字体"与"编辑器字体"不同侧重的配置，消除重复。

- [ ] **B4 强调色与 MC 主题解耦提示**
  - 问题：MC 主题 `--accent` 固定 `#6BA84E`，自定义强调色无效且无提示。
  - 证据：`themes.css:110`；`SettingsView.tsx:45`（ACCENT_PALETTE 仅 6 色）
  - 方案：MC 主题下选中自定义色时展示提示（消费 `settings.accentColorMcHint` key）；提供自由取色器。

### C. 番茄钟 × 写作闭环（v3.4 核心）

- [ ] **C1 与写作目标绑定**
  - 问题：番茄钟与写作字数/目标完全脱钩。
  - 方案：工作区增加"写作目标"（每日/每周字数）；专注会话期间统计字数增量，完成后更新目标进度；里程碑达成触发成就。

- [ ] **C2 每日/每周专注统计**
  - 问题：有 achievements 计数但无时间维度图表。
  - 方案：统计视图新增"专注趋势"（日/周柱状图）；复用 `statistics` 模块图表基建。

- [ ] **C3 系统级通知**
  - 问题：仅声音 + toast，无系统通知（Tauri Notification 插件）。
  - 方案：专注/休息结束发送系统通知；任务栏闪烁（Windows）。

- [ ] **C4 消费 `pomodoro.milestone`**
  - 问题：翻译 key 已存在但组件未用。
  - 证据：`src/components/ui/PomodoroTimer.tsx`（milestone 未使用）
  - 方案：里程碑文案接入 C1 的目标进度展示。

### D. i18n 补全（v3.3 并行）

- [ ] **D1 补齐 en.json 51 个缺失 key**
  - 涉及：整个 `onboarding` 块（15）、`settings.feature*`（10）、各视图 empty 状态、`timeline.event.images` 等。
  - 证据：zh-CN.json 801 key vs en.json 750 key（zh 有而 en 无 51 个）
  - 方案：逐块补齐，新增 `settings.startup/shortcuts/help` 对应 tab 或删除僵尸 key。

## 三、分阶段路线图（长期目标）

```
v3.3 清晰度与一致性 ──→ v3.4 写作闭环 ──→ v4.0 深度创作 ──→ v4.1+ 打磨发布
   时间轴可读性          番茄钟×目标         地图/VN/世界观      美术统一/日文
   字体修复               每日统计            AI Agent 工作流     性能/无障碍
   i18n 补全              系统通知            导出增强
   + 工程门禁提交
```

### Phase 1 — v3.3「看得清楚，用得顺手」（清晰度与一致性）

**目标**：用户打开时间轴第一眼能读明白；字体主题真正生效；英文用户不再看到中文。

| 内容 | 优先级 |
|---|---|
| A1–A10 时间轴清晰度十条 | 🔴 全部 |
| B1–B4 字体/主题一致性 | 🔴 全部 |
| D1 i18n en 补全 | 🟠 |
| E1 提交 CI 门禁 | 🔴 前置 |

**验收标准**：
- 时间轴在无 hover 状态下，连线/子行/相对事件均能一眼辨识（对照 5 张 before/after 截图）
- `font-pixel` 类在产物 CSS 中存在，MC 番茄钟像素字真正生效
- en.json 缺失 key 归零，英文界面无中文回退
- CI 上 backend + e2e job 出现绿色运行记录

### Phase 2 — v3.4「写下去，有反馈」（番茄钟 × 写作闭环）

**目标**：番茄钟从"计时器"升级为"写作伴侣"——专注、目标、统计、通知四者闭环。

| 内容 | 优先级 |
|---|---|
| C1 写作目标绑定 | 🔴 |
| C2 每日/每周专注统计 | 🟠 |
| C3 系统通知 | 🟠 |
| C4 里程碑文案 | 🟡 |

**验收标准**：
- 设定每日 1000 字目标后，番茄钟专注 2 个会话（各写 300 字）→ 目标进度 60% 正确显示
- 统计视图出现专注趋势图；系统通知在 Tauri 桌面端触发成功
- 新增 E2E：设置目标 → 专注 → 验证进度（mock 后端）

### Phase 3 — v4.0「讲好复杂故事」（深度创作增强）

**目标**：把路线图中沉睡的候选方向逐一落地为可用功能。

| 内容 | 说明 |
|---|---|
| 地图增强 | 地点分组/图层开关、角色足迹连线、打印/PDF/图片导出 |
| VN 增强 | 立绘插槽拖拽定位、完整预览播放器（带分支选择）、Ren'Py 导出音频/转场/变量 |
| 世界观实体 | 种族/物种/宗教/职业实体管理、实体与角色·地点·事件关联、设定冲突检测 |
| AI Agent 工作流 | 自动整理大纲、发现时间轴漏洞、长上下文 RAG、输出版本回溯 |

**验收标准**（每项独立）：
- 地图：40+ 地点分组后图层切换流畅，导出 PDF 版式正确
- VN：预览播放器可完整走通一条分支路径
- AI：一条"发现时间轴漏洞"指令返回 3+ 条可操作建议

### Phase 4 — v4.1+「像件艺术品」（打磨与发布）

**目标**：从"能用"到"好看好用"。

| 内容 | 说明 |
|---|---|
| UI 美术统一 | 统一空状态插画、卡片质感升级（纸质/玻璃拟物）、间距阴影 token 全量对齐 |
| 日文翻译补全 | `ja` locale 新建并补全（zh 801 key 为基准） |
| 性能优化 | 长工作区（1000+ 事件）滚动帧率、React 渲染优化、Rust 层查询缓存 |
| 无障碍 | 键盘导航全覆盖、ARIA 补全、对比度 AA 达标 |

## 四、迭代执行纪律（每阶段通用）

1. **每次改动遵循 `AGENTS.md`**：先读后写、禁 `any`、禁裸 CSS、禁改已发布迁移。
2. **测试先行**：每项优化点至少 1 个单元测试 + 涉及时间轴时跑 `tests/e2e/timeline-` 子集。
3. **截图留证**：UI 改动前后截图存入 `docs/截图留证/`（git 跟踪），方便对比验收。
4. **文档同步**：每阶段结束更新本文件状态、`更新日志.md`、`交接文档.md`、`产品路线图.md`。
5. **版本发布**：遵循 `AGENTS.md` §4.4 发布清单；`check:version`（E2）全绿后再打 tag。
