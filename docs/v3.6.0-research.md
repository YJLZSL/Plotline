# v3.6.0 时间轴重做调研

> 2026-08-15 ｜ 触发：用户反馈相对时间轴"奇怪、不直观"，要求调研同类工具后重做界面。

## 一、用户反馈要点

- 纯相对时间轴被拉到 2026 Q1 – 2030 Q1 的 4–10 年跨度，两个事件卡在左侧，右侧大段空白；"今天"线出现在相对时间轴中造成困惑。
- 事件卡片与顶部标尺之间视觉上"断开"：时间信息藏在卡片内部，网格线太弱，时间感不强。
- 卡片信息密度低、留白多；筛选栏拥挤；轨道列表单薄；左右视觉重心失衡。

## 二、竞品调研结论

### Aeon Timeline（Subway View）
- **轨道即角色/故事线**：左侧固定轨道头（头像 + 名称 + 折叠），横滚时始终知道当前看的是哪条线。
- **统一标尺 + 极淡垂直网格**：跨轨道比对各事件的时间点，刻度随 zoom 自适应。
- **渐进式披露**：节点保持小巧，选中后放大显示详情气泡。
- **彩色连线**：跨轨道关联线使用颜色区分关系类型，不抢卡片视觉。
- 来源：<https://www.aeontimeline.com/guides/the-subway-view>

### Plottr Timeline
- **Chapter Headings + Plotlines + Scene Cards**：章节标题作为横向分组带，故事线作为行，场景卡片拖拽排布。
- **时间轴工具栏**：Filter / Flip / Attributes / Zoom / Scroll / Export / Structure，把低频能力收纳在菜单。
- **颜色即信息**：章节、故事线、单卡都可自定义颜色；过滤可按角色/地点/标签/颜色。
- 来源：<https://docs.plottr.com/article/54-timeline-overview>

### 通用 UX 原则（Eleken）
- 时间轴的首要任务是**让人几秒内理解时间信息**，不是展示更多事件。
- 清晰时间刻度、颜色编码、依赖关系可视化、渐进式披露、缩放层级。
- 密集数据用 grouping/clustering + 过滤 + 渐进披露，不要一次画满。
- 来源：<https://www.eleken.co/blog-posts/timeline-ui-design>

## 三、本次重做决策

1. **相对时间轴只占内容实际范围**：新增 `compactBounds`，相对模式标尺/网格/画布宽度按事件实际位置 + 1.5 个步长计算，不再预留 8–10 年。
2. **相对刻度标记**：在标尺上直接渲染 `#1` / `#2` 故事顺序点（`relativeMarkers`），用户不再依赖伪日历日期。
3. **相对模式隐藏 Today 线**：相对时间轴没有真实"今天"；工具栏缩放档位显示"相对"。
4. **标尺强化**：主刻度间交替时间带背景、更粗主刻度线、accent 底部刻度、标签加大；标尺高度 44→52。
5. **事件卡片视觉重做**：
   - 圆角 8→10，柔和双层阴影，默认 1px 边框（选中才用 accent ring）。
   - 左侧轨道色条加宽并圆角；状态点加 ring。
   - 时间范围放进带日历图标的浅色胶囊，与顶部标尺形成视觉呼应。
   - 标题 semibold、内边距收紧，减少无效留白。
6. **轨道行强化**：斑马纹更清晰、hover 高亮、拖放目标 ring；轨道色标加宽。
7. **AI Agent 工作流切片（v4.0 预热）**：时间轴 More 菜单新增"AI 检查时间轴漏洞"，面板打开后自动执行 `check_timeline_consistency` 快捷动作。

## 四、验证方式

- `vision-tools` 对新旧截图进行 glance 对比确认：新相对时间轴标尺收窄到 2026-01 ~ 2026-06，`#1/#2` 标记清晰可见。
- 新增/保留 E2E 断言：`relative-marker` 可见、相对时间轴 ruler 跨度可控（通过视觉截图留证）。
- 保持既有 timeline 门禁 35+ 用例全绿。
